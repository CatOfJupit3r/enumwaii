## Ask or report

Search [existing issues](https://github.com/CatOfJupit3r/enumwaii/issues) before opening a new one. Use the bug form for reproducible library behavior and the feature form for a concrete API or integration proposal.

Include the package version, TypeScript and runtime versions, relevant configuration, the smallest reproduction you can provide, and the expected and actual behavior. A repository or playground is especially useful for inference and lint parser-service issues.

Support is community-maintained and does not have a guaranteed response time. Questions about application code outside enumwaii's behavior may be redirected to the relevant framework or validator.

Potential vulnerabilities must be reported privately through [SECURITY.md](SECURITY.md), not through a public support issue.
