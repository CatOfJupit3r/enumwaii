published TypeScript exports. The source comments are the authority: changes to
an export and its documentation are reviewed and released together.

- [`eslint-plugin-enumwaii`](./eslint-plugin-enumwaii/index.md) covers the plugin,
  presets, rule registry, and individual rule implementations.

The generated reference complements the authored guides. Start with
[Getting started](../getting-started.md) if you are choosing a member surface or
