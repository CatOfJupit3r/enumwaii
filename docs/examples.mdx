The repository examples are independent applications with package manifests, runnable commands, tests, type contracts, and READMEs explaining their boundary and recovery paths.

<Callout type="warn" title="Hosted demos exercise the portable slice">
  StackBlitz runs the browser or Node.js path inside a WebContainer. It cannot
  prove Hono's Bun, Deno, or workerd paths or NestJS's Docker-backed MongoDB
  service. Use the checked-in runtime commands for those environments.
</Callout>

The hosted links import the complete repository so the unpublished local copy of enumwaii remains available through each example's `file:` dependency. They install only the selected example and its dependencies, then build the local library before starting.

## Everyday development seams

- Forms use TanStack Form in the Solid application and a dependency-free native approach in Vue.
- TanStack Table drives a searchable and sortable operations grid in Next.js.
- Next.js, TanStack Start, and Vue parse URL or persistence state.
- Hono uses Drizzle with embedded PGlite on Node, Bun, and Deno; its shared database-free status routes also run in Cloudflare workerd with Node compatibility disabled. NestJS uses Mongoose with a checked-in MongoDB Compose service.
- Server examples cover JSON, form data, route parameters, request/response schemas, error mapping, and serialized branded strings.
- The Hono runtime suite keeps one status-boundary contract constant across native Bun and Deno servers and Cloudflare workerd.

Every application includes invalid and ambiguous inputs alongside its successful flow.
